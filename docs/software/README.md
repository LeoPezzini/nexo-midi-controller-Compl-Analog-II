# Demostraciones de software

El objetivo de estas pruebas es demostrar que MIDI describe eventos y valores,
pero no impone una aplicacion concreta. El mismo hardware puede controlar
musica, iluminacion o produccion audiovisual mediante diferentes mapeos.

| Aplicacion | Uso previsto | Estado |
|---|---|---|
| QLC+ 5.2.2 | RGB, intensidad, escenas y blackout | En configuracion |
| OBS Studio | Escenas, grabacion, mute y transiciones | Pendiente |
| FL Studio | Notas, instrumentos virtuales y parametros CC | Pendiente |

Cada guia registrara version del programa, configuracion, asignaciones MIDI,
capturas y resultado del ensayo para que la demostracion pueda reproducirse.
