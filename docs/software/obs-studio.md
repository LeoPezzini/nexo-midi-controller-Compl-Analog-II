# OBS Studio — control audiovisual mediante MIDI

## Objetivo

Demostrar el uso del controlador fuera del ambito musical mediante cambio de
escenas, activacion de fuentes, mute y control de niveles.

## Mapeo preliminar

| Control | Funcion prevista |
|---|---|
| B1-B4 | Seleccion de escenas |
| B5 | Iniciar/detener grabacion |
| B6 | Activar/desactivar microfono |
| P1 | Nivel de una fuente de audio |
| P2 | Nivel de otra fuente o parametro de transicion |

La herramienta de integracion y su version se definiran despues de comprobar su
compatibilidad con la version instalada de OBS Studio. No se considera parte del
firmware: es una capa de asignacion en la computadora.
